# Moolish: open-source TD Sequential tools

[Moolish](https://moolish.com) is a real-time crypto market scanner with Telegram alerts. Here we publish free, tested implementations of Tom DeMark's TD Sequential indicator (TD Setup / TD9, TD Countdown 13, TDST levels), all written from one plain-English rule book and checked against the same reference data.

| Repository | What it is |
|---|---|
| [td-sequential](https://github.com/moolish-com/td-sequential) | TD Sequential indicator for JavaScript and TypeScript (npm `td-sequential-indicator`) |
| [td-sequential-python](https://github.com/moolish-com/td-sequential-python) | TD Sequential indicator for Python and pandas (PyPI `td-sequential`) |
| [td-sequential-pine-script](https://github.com/moolish-com/td-sequential-pine-script) | TD Sequential indicator for TradingView, Pine Script v6, with alerts |
| [td-sequential-screener](https://github.com/moolish-com/td-sequential-screener) | Command-line screener that lists the crypto pairs that just printed a 9 or a 13 |

No install needed: the [free TD Sequential counter](https://moolish.com/tools/td-sequential-counter/) checks the current count on any crypto pair in your browser. New to the method? Start with the [TD Sequential guide](https://moolish.com/learn/td-sequential/).
